# MySoundpad

โปรแกรม soundboard สำหรับ Windows เล่นเสียงเข้าไมโครโฟน ให้เพื่อนใน Discord หรือในเกมได้ยิน พร้อมปุ่มลัดที่กดได้แม้กำลังเล่นเกมอยู่ ใช้งานฟรี ไม่มีจำกัดเวลา

---

## ✨ ความสามารถ

### เล่นเสียง
- 🎙 **เล่นเสียงเข้าไมค์**: ส่งเสียงไปที่ไมค์เสมือนผ่าน [VB-CABLE](https://vb-audio.com/Cable/) คนใน Discord หรือในเกมจะได้ยิน
- 🎧 **ฟังเองพร้อมกัน**: เล่นออกหูฟังของเราไปพร้อมกัน ปรับความดังแยกจากฝั่งไมค์ได้
- 🎤 **ส่งเสียงพูดผ่านไปด้วย**: ผสมเสียงไมค์จริงเข้าไปกับเสียงเอฟเฟกต์ เพื่อนได้ยินทั้งเสียงพูดและเสียงเอฟเฟกต์
- 🔊 **เล่นซ้อนกันหลายเสียง** หรือตั้งให้หยุดเสียงเก่าเมื่อเล่นเสียงใหม่ก็ได้
- 🛡 **Soft limiter**: กดเสียงที่ดังเกินให้นุ่มลง ไม่แตก
- รองรับไฟล์ **mp3, wav, ogg, flac, aiff**
- 🔁 **เล่นวน**: วนต่อกันไม่มีช่วงเงียบ กดปุ่มลัดซ้ำเพื่อหยุด
- ✋ **กดค้างเพื่อเล่น**: เล่นตอนกดปุ่มลัดค้าง ปล่อยแล้วหยุดทันที (ค่อยๆ เบาลง ไม่มีเสียงคลิก)

### จัดระเบียบ
- 📂 **หมวดหมู่ / แท็บ**: สร้างหมวดเอง เช่น มีม / เพลง / เกม ย้ายเสียงข้ามหมวดได้
- ⭐ **รายการโปรด**: ติดดาวเสียงที่ใช้บ่อย แล้วดูรวมในแท็บ ⭐ โปรด
- ↕ **ลากเรียงลำดับ** เสียงในรายการ
- 🖱 **ลากไฟล์มาวาง**: ลากไฟล์เสียง / โฟลเดอร์ / ลิงก์ YouTube จากเบราว์เซอร์มาวางบนรายการ

### เปลี่ยนเสียงพูด (Voice changer)
- 🤖 ใส่เอฟเฟกต์ให้เสียงไมค์จริงที่ส่งไปให้เพื่อน: 🐿 เสียงสูง, 👹 เสียงต่ำ, 🤖 หุ่นยนต์, 📻 วิทยุ, 🏛 ก้อง
- ปรับความแรงได้ ฟังเสียงตัวเองได้ และตั้งปุ่มลัดสลับเปิด/ปิดระหว่างเล่นเกมได้

### ปุ่มลัด
- ⌨ **ปุ่มลัดแบบ global**: กดได้แม้กำลังอยู่ในเกมหรือโปรแกรมอื่น
- ตั้งได้ทีละเสียง รองรับคีย์ผสม เช่น **Alt+1, Ctrl+2, Ctrl+Alt+3, Ctrl+Shift+F, Ctrl+Num5** รวมถึง F1–F24 และ Numpad
  - ใช้ปุ่ม **Win** ไม่ได้ เพราะ Windows ใช้อยู่แล้ว (เช่น Win+1 เปิดแอปตัวแรกบน taskbar)
  - **Shift+Numpad** ใช้ไม่ได้ เพราะเมื่อเปิด NumLock อยู่ Windows จะปล่อยปุ่ม Shift ให้เอง ให้ใช้ Ctrl หรือ Alt+Numpad แทน
- มีปุ่มลัด **หยุดทุกเสียง** (ค่าเริ่มต้นคือ Pause)
- ปิดปุ่มลัดชั่วคราวได้ เช่น ตอนพิมพ์แชท

### YouTube
- 🎬 **ดาวน์โหลดเสียงจาก YouTube**: วางลิงก์ (รองรับ Shorts) แล้วเสียงจะเข้ารายการให้อัตโนมัติ
- ✂ **ตัดช่วงด้วยหลอดเลื่อน 2 หมุด**: ลากเลือกตั้งแต่ตรงไหนถึงตรงไหน ปรับละเอียดได้ทีละ 0.1 วินาที และซูมเข้าช่วงที่เลือกได้
- 🎧 **ฟังตัวอย่างก่อนตัด**: ฟังช่วงที่เลือก / 3 วิแรก / 3 วิสุดท้าย และกด `[` `]` ตั้งจุดตอนที่ได้ยินท่อนที่ต้องการ เสียงตัวอย่างออกหูฟังอย่างเดียว เพื่อนไม่ได้ยิน
- 🌐 **โหมดสตรีม**: เล่นตรงจาก YouTube โดยไม่เก็บไฟล์ในเครื่อง ใช้ RAM คงที่แม้คลิปยาวเป็นชั่วโมง
- ⬆ **อัปเดตตัวโหลดในโปรแกรม**: ตรวจ SHA-256 กับไฟล์ทางการก่อนใช้ทุกครั้ง

### อื่นๆ
- 🔄 **อัปเดตในแอป**: เช็กเวอร์ชันใหม่จาก GitHub วันละครั้ง กดปุ่มเดียวโหลด ตรวจ SHA-256 ติดตั้ง แล้วเปิดแอปใหม่ให้เอง
- 💾 บันทึกรายการเสียง ปุ่มลัด และการตั้งค่าอัตโนมัติ
- 🔍 ค้นหาเสียงตามชื่อ
- 🪶 เบา: ใช้ CPU ต่ำกว่า 0.5% และ RAM ประมาณ 70 MB
- 🧪 มีโหมดตรวจตัวเอง (`--selftest`) ไว้หาสาเหตุเวลามีปัญหา

## 📥 วิธีติดตั้ง

### ขั้นที่ 1: ติดตั้ง MySoundpad (และ VB-CABLE ไปพร้อมกัน)
1. ดาวน์โหลด **`MySoundpad-Setup-x.x.x.exe`** จากหน้า [Releases](https://github.com/inkza1150za/MySoundpad/releases)
2. เปิดไฟล์ ถ้าขึ้น **"Windows protected your PC"** ให้กด **More info → Run anyway**
   > โปรแกรมไม่มีใบรับรองการเซ็นโค้ด (code signing) Windows จึงเตือนแบบนี้กับโปรแกรมที่ยังไม่รู้จัก
3. ทำตามขั้นตอนในตัวติดตั้ง MySoundpad ลงได้**โดยไม่ต้องใช้สิทธิ์แอดมิน**
4. **ถ้าเครื่องยังไม่มี VB-CABLE** (ไมค์เสมือนที่ใช้ส่งเสียงเข้า Discord/เกม) จะมีตัวเลือก
   **☑ ดาวน์โหลดและติดตั้ง VB-CABLE (ฟรี) ให้ด้วย** ติ๊กไว้ให้แล้ว:
   - ตัวติดตั้งจะดาวน์โหลดจาก**เว็บทางการของ VB-Audio** และ**ตรวจลายเซ็นดิจิทัล**ก่อน ถ้าไฟล์ไม่ใช่ของ VB-Audio จริงจะไม่เปิดใช้
   - หน้าต่างติดตั้ง VB-CABLE จะเปิดขึ้น → กด **Yes** ที่หน้าต่างขอสิทธิ์แอดมิน → กด **Install Driver** → รอจนเสร็จแล้วปิดหน้าต่างนั้น
   - ตอนจบตัวติดตั้งจะขอให้**รีสตาร์ทเครื่อง** (จำเป็นสำหรับไดรเวอร์)
   - ถ้าดาวน์โหลดหรือติดตั้งไม่สำเร็จ จะเปิดหน้าเว็บให้ติดตั้งเองตาม [ติดตั้ง VB-CABLE เอง](#ติดตั้ง-vb-cable-เอง)
5. หลังรีสตาร์ท ถ้าเสียงในเครื่องหายไป ให้คลิกไอคอนลำโพงที่มุมขวาล่าง แล้วเลือกกลับไปเป็นลำโพงหรือหูฟังของคุณ
6. เปิด **MySoundpad** จาก shortcut บนเดสก์ท็อปหรือ Start menu

#### ติดตั้ง VB-CABLE เอง
ใช้กรณีไม่ได้ติ๊กตัวเลือกด้านบน หรือการติดตั้งอัตโนมัติไม่สำเร็จ
1. ดาวน์โหลดจากเว็บทางการ **https://vb-audio.com/Cable/** เท่านั้น อย่าโหลดจากเว็บอื่น
2. แตกไฟล์ zip แล้ว**คลิกขวาที่ `VBCABLE_Setup_x64.exe` → Run as administrator**
3. กด **Install Driver** แล้วรอจนติดตั้งเสร็จ
4. **รีสตาร์ทเครื่อง**

### ขั้นที่ 2: ตั้งค่า Discord หรือเกม (ทำครั้งเดียว)
**Discord:** User Settings → Voice & Video
| ตั้งค่า | ค่าที่ใช้ |
|---|---|
| Input Device | **CABLE Output (VB-Audio Virtual Cable)** |
| Noise Suppression | **None** (ไม่อย่างนั้นเพลงจะถูกตัดจนจมหรือขาดๆ หายๆ) |
| Echo Cancellation | **ปิด** |
| Automatic Gain Control | **ปิด** |
| Input Sensitivity | ปิดโหมดอัตโนมัติ แล้วลากแถบไปทางซ้ายเกือบสุด |

**เกม:** ตั้งไมค์ในเกมเป็น **CABLE Output** แบบเดียวกัน

ทดสอบ: ใน Discord หน้า Voice & Video กด **Let's Check** แล้วลองพูดและกดเล่นเสียง

| เปลี่ยนชื่อ / ลบ | **✏ เปลี่ยนชื่อ** / **🗑 ลบ** (ไฟล์จริงไม่ถูกลบ) |

### หมวดหมู่และรายการโปรด
- แถบเหนือช่องค้นหา: **ทั้งหมด / ⭐ โปรด / หมวดที่สร้างเอง** กด **＋ หมวดใหม่** เพื่อเพิ่ม
- **คลิกขวาที่แท็บหมวด** = เปลี่ยนชื่อ / ลบหมวด (ลบหมวดแล้ว เสียงยังอยู่ในแท็บ "ทั้งหมด")
- คลิก **☆** หน้าชื่อเสียงเพื่อติดดาว
- เพิ่มเสียงตอนเปิดแท็บไหนอยู่ เสียงจะเข้าหมวดนั้น ช่องค้นหาค้นในแท็บที่เปิดอยู่
- ปุ่มลัดใช้ได้กับทุกเสียงเสมอ ไม่ว่าจะเปิดแท็บไหน

### โหมดเล่น (คลิกขวาที่เสียง → 🔁 โหมดเล่น)
| โหมด | กดปุ่มลัด | กดซ้ำ / ปล่อยปุ่ม |
|---|---|---|
| ปกติ | เล่นจนจบ | — |
| 🔁 เล่นวน | วนไม่หยุด | **กดซ้ำ = หยุด** |
| ✋ กดค้าง | เล่นตอนกดค้าง | **ปล่อยปุ่ม = หยุด** |

> รายการ 🌐 สตรีม YouTube ที่ตั้งเล่นวน จะมีช่วงเงียบสั้นๆ ตรงรอยต่อ เพราะต้องเชื่อมต่อใหม่ทุกรอบ

### 🤖 เปลี่ยนเสียงพูด
1. ติ๊ก **"ส่งเสียงไมค์จริงผ่านด้วย"** (เอฟเฟกต์ใส่ให้เสียงไมค์จริงที่ส่งไปให้เพื่อน)
2. เลือกเอฟเฟกต์ในแถบ **🤖 เปลี่ยนเสียง** ใต้รายการ แล้วปรับ **ความแรง**
3. ติ๊ก **"ฟังเสียงตัวเอง"** เพื่อลองฟังผ่านหูฟัง (ฟังเสร็จแล้วปิด จะได้ไม่ได้ยินเสียงตัวเองตอนคุย)
4. ตั้งปุ่มลัดที่ปุ่ม **"สลับ: -"** เพื่อเปิด/ปิดเอฟเฟกต์ล่าสุดระหว่างเล่นเกม
> เสียงสูง/ต่ำหน่วงเพิ่มประมาณ 25 ms เอฟเฟกต์อื่นแทบไม่หน่วงเพิ่ม เสียงเอฟเฟกต์จากไฟล์ไม่ได้รับผลกระทบ

> 💡 แนะนำให้ตั้งปุ่มลัดเป็น **Numpad 0–9** เพราะไม่ชนกับปุ่มในเกม และต้องเปิด NumLock ไว้

### จาก YouTube
1. คัดลอกลิงก์ แล้วกด **🎬 จาก YouTube** ลิงก์จะถูกวางให้อัตโนมัติ และโปรแกรมจะโหลดชื่อกับความยาวคลิปมาให้
2. **เลือกช่วงที่จะตัด** (ไม่ตัดก็ได้ จะได้ทั้งคลิป)

   ```
             เริ่ม 1:23.0              จบ 1:30.0
                 ▼                        ▼
   0:00 ├────────◆████████████████████████◆──────────┤ 3:45
                            │ ← ตำแหน่งที่กำลังฟัง
   ```
   | ทำอะไร | ผล |
   |---|---|
   | ลากหมุด ◆ ซ้าย / ขวา | เลื่อนจุดเริ่ม / จุดจบ ปล่อยแล้วจะเล่นให้ฟังทันที |
   | ลากแถบสีระหว่างหมุด | ย้ายทั้งช่วง ความยาวเท่าเดิม |
   | คลิกที่ไหนก็ได้บนหลอด | ฟังจากจุดนั้น |
   | ปุ่ม `-1s` `-0.1s` `+0.1s` `+1s` หรือพิมพ์เวลา | ปรับละเอียด |
   | **`[`** / **`]`** ระหว่างฟัง | ตั้งจุดเริ่ม / จุดจบ ตรงที่กำลังได้ยิน |
   | **Space** | ฟังช่วงที่เลือก / หยุดฟัง |
   | 🔍 ซูมเข้าช่วงที่เลือก | ขยายหลอดให้ลากละเอียดขึ้น เหมาะกับคลิปยาว |

   > 🎧 เสียงตัวอย่างออก**หูฟังคุณอย่างเดียว** ไม่เข้าไมค์ และมีแถบความดังแยกของตัวเองในหน้าต่างนี้
3. ใส่ชื่อเสียงได้ (ไม่ใส่จะใช้ชื่อคลิป)
4. เลือกวิธีเล่น:
   - **ดาวน์โหลดเก็บไว้**: กดแล้วเสียงออกทันที เหมาะกับเสียงมีมและเสียงที่ใช้ปุ่มลัด
   - **🌐 สตรีม**: ไม่เก็บไฟล์ เสียงจะออกหลังกดประมาณ 1–2 วินาที (เล่นซ้ำแทบทันที) เหมาะกับเพลงยาว
5. ถ้าวันหนึ่งโหลดไม่ได้ ให้กด **⬆ อัปเดตตัวโหลด** แล้วเปิดโปรแกรมใหม่

|---|---|
| เสียงที่หูฉัน | ความดังที่เราได้ยินเอง |
| เสียงเข้าไมค์ | ความดังที่เพื่อนได้ยิน (แนะนำ 70–100) |
| ไมค์จริง | ความดังของเสียงพูดเรา (ลากเป็น 0 = ปิดเสียงพูด) |
| ส่งเสียงไมค์จริงผ่านด้วย | ⚠ ต้องเปิดไว้ ไม่อย่างนั้นเพื่อนจะไม่ได้ยินเสียงพูดของคุณ |

### 🔄 อัปเดตโปรแกรม (ตั้งแต่ 1.4.0)
- เปิดโปรแกรมแล้ว แอปจะเช็กเวอร์ชันใหม่จาก [GitHub Releases](https://github.com/inkza1150za/MySoundpad/releases) **วันละครั้ง**
- ถ้ามีเวอร์ชันใหม่ ปุ่มมุมขวาบนจะเปลี่ยนเป็น **⬆ อัปเดต x.x.x** (สีชมพู) และแถบสถานะขึ้นป้าย **มีอัปเดต**
- กดปุ่ม → อ่านว่ามีอะไรใหม่ → **⬆ อัปเดตเลย** แอปจะดาวน์โหลด **ตรวจ SHA-256** แล้วปิดตัวเอง ติดตั้งทับ และเปิดใหม่ให้ รายการเสียงและการตั้งค่าอยู่ครบ
- **ข้ามเวอร์ชันนี้**: จะไม่เตือนเวอร์ชันนั้นอีก (กด 🔄 ตรวจสอบอัปเดต เองยังเห็น)
- กด **🔄 ตรวจสอบอัปเดต** เพื่อเช็กเองได้ตลอด และปิดการเช็กอัตโนมัติได้ที่ช่อง "ตรวจสอบเวอร์ชันใหม่อัตโนมัติ"
- เวอร์ชัน 1.3.0 ลงมาไม่มีฟีเจอร์นี้ ต้องโหลดตัวติดตั้งใหม่จากหน้า Releases เองครั้งแรกครั้งเดียว

## 📂 ข้อมูลเก็บที่ไหน

| อะไร | ที่อยู่ |
|---|---|

### 🗑 ถอนการติดตั้ง
1. ปิด MySoundpad ก่อน
2. เลือกวิธีใดวิธีหนึ่ง:
   - **Settings → Apps → Installed apps → MySoundpad → Uninstall**
   - หรือดับเบิลคลิก **"ถอนการติดตั้ง MySoundpad"** ในโฟลเดอร์โปรแกรม `%LOCALAPPDATA%\Programs\MySoundpad`
3. ตอนท้าย ตัวถอนการติดตั้งจะถามว่า **"ลบข้อมูลของ MySoundpad ด้วยไหม?"**
   - **ใช่:** ลบรายการเสียง ปุ่มลัด การตั้งค่า และเพลงที่ดาวน์โหลดจาก YouTube (`%APPDATA%\MySoundpad`)
   - **ไม่** (ค่าเริ่มต้น): เก็บไว้ ติดตั้งใหม่ภายหลังจะได้รายการเสียงเดิมกลับมา
   - ไฟล์เสียงที่คุณเพิ่มจากโฟลเดอร์อื่น (เช่น Downloads) จะไม่ถูกลบไม่ว่าจะเลือกแบบไหน
4. **VB-CABLE ไม่ถูกลบ** เพราะเป็นไดรเวอร์แยกที่โปรแกรมอื่นอาจใช้อยู่ ถ้าจะลบ ให้เปิด `VBCABLE_Setup_x64.exe` ด้วย Run as administrator แล้วกด **Remove Driver** จากนั้นรีสตาร์ทเครื่อง

> ถอนแบบเงียบ (สำหรับสคริปต์): `uninstall\unins000.exe /VERYSILENT` จะเก็บข้อมูลไว้ เพิ่ม `/deletedata=1` ถ้าต้องการลบด้วย

### รันจากซอร์สโค้ด
ต้องมี [Python 3](https://www.python.org/downloads/) (ทดสอบกับ 3.14)
```bash
pip install sounddevice soundfile numpy pynput yt-dlp imageio-ffmpeg tkinterdnd2
```
```bash
python soundpad.py
```
หรือดับเบิลคลิก `run_soundpad.bat` ตอนรันจากซอร์สโค้ด ข้อมูลจะเก็บไว้ในโฟลเดอร์โปรเจกต์ (`soundpad_data.json` และ `sounds/` ถูก gitignore ไว้แล้ว)

### Build exe และตัวติดตั้ง
1. ติดตั้งเครื่องมือ (ครั้งเดียว):
   ```bash
   pip install pyinstaller pillow
   ```
   ```bash
   winget install JRSoftware.InnoSetup
   ```
2. ดับเบิลคลิก `build.bat`
3. ผลลัพธ์:
   - `build\dist\MySoundpad\MySoundpad.exe`: ตัวโปรแกรม (แบบโฟลเดอร์)
   - `build\installer\MySoundpad-Setup-x.x.x.exe`: ตัวติดตั้ง สำหรับอัปโหลดขึ้น GitHub Releases

### ออกเวอร์ชันใหม่
1. แก้เลขเวอร์ชันให้ตรงกันทั้ง 3 จุด แล้วรัน `build.bat`:
   - `mysoundpad/config.py` → `APP_VERSION`
   - `installer.iss` → `#define MyAppVersion`
   - `build_assets/version_info.txt` → `filevers`, `prodvers`, `FileVersion`, `ProductVersion`
2. สร้าง GitHub Release ที่ repo นี้ ด้วย tag `vX.Y.Z` (ต้องตรงกับ `APP_VERSION`) แล้วแนบไฟล์ `MySoundpad-Setup-X.Y.Z.exe`
   - แอปที่ติดตั้งไว้จะเห็นเวอร์ชันใหม่เอง (อ่านจาก `releases/latest` และข้าม draft / pre-release)
   - แอปตรวจไฟล์กับค่า SHA-256 ที่ GitHub บันทึกให้ไฟล์แนบอัตโนมัติ ถ้าไม่มี จะหาค่า SHA-256 ในคำอธิบาย Release แทน ถ้าไม่เจอทั้งคู่ จะไม่ติดตั้งอัตโนมัติ (ให้ผู้ใช้เปิดหน้าดาวน์โหลดเอง)
   - ทดลองก่อนปล่อยจริงได้โดยติ๊ก **pre-release** แอปของผู้ใช้จะยังไม่เห็น
3. ⚠️ ความปลอดภัยของการอัปเดตขึ้นกับบัญชี GitHub ที่ปล่อย Release ควรเปิด 2FA
